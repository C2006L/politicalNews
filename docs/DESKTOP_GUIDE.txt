时政自习室 · Windows 本地版

1. 解压整个压缩包，再双击 StudyRoom.exe。不能只复制 exe，_internal 文件夹必须保留。
2. 启动后自动打开浏览器。首次使用数据库为空，点击启动窗口里的“更新近期新闻”。
3. 保持启动窗口打开；退出窗口会停止本地服务。重复启动不会打开第二份数据库进程。
4. 本版包含 Python 运行环境，不需要安装 Python。仅支持 Windows x64。

公众号资料：
阅读功能不要求 Docker。公众号定向采集仍需另外安装 Docker Desktop、部署 WeRSS、
扫码授权并订阅公众号。启动窗口的“设置公众号资料源”选择 WeRSS 的 db.db，
重新启动应用，再点“导入公众号资料”。此设置不会代替扫码或自动部署 WeRSS。
公众号授权由使用者自己维护；本包不含开发者的登录凭据或现有文章。

数据与升级：
数据保存在 %LOCALAPPDATA%\PoliticalNewsStudy，可通过启动窗口打开该目录。
study.db 为资料数据库，settings.json 为本机配置，application.log 为运行日志。
数据库升级前自动备份到 backups。升级程序时退出应用并替换整个程序目录；
用户数据另存于上述目录，不会随解压替换丢失。
正式启动固定使用 127.0.0.1:18764，收藏和已读保存在所用浏览器，重启可继续使用。
如果该端口被其他程序占用，应用不会擅自切换端口，请先关闭占用它的程序。
尚未包含自动更新、安装程序、代码签名或 WeRSS 一键部署。
