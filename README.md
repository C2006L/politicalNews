# 时政聚合平台 (Political News)

面向两类用户：
- 考公/考编备考用户（需要稳定、可回看、可检索的时政资料）
- 日常关注时政用户（需要权威来源、更新及时、阅读简洁）

## 功能概览

- 每日阅读首页：综合、考研政治、公考常识、申论面试四种方向，支持主题筛选和分页
- 阅读整理：同日同标题稿件合并展示，推荐依据可展开；仅按规则排序，不代表命题预测或完整事件聚合
- 阅读工具：已读标记、浏览器本地收藏、原文链接和往期回顾；收藏不跨设备同步
- 内容区分：原文导读与规则阅读提示分别展示，当前未接入 AI 总结

- 权威来源聚合：政府网、人民网、新华网、中国新闻网、央视网、外交部等
- 页面导航：今日时政、昨日时政、分类专题、数据源、按月归档、同步状态
- 检索能力：关键词搜索、年份筛选（最低到 2025）、按月归档展开
- 数据策略：每小时自动同步（北京时间），支持手动同步和回填
- 内容策略：保留原文链接，不做 AI 改写
- 终端适配：桌面 + 移动端自适应

## 本地配置与离线测试

使用 Python 3.13 安装 `requirements.txt` 与 `requirements-dev.txt`。应用会在数据库初始化前自动加载项目根目录 `.env`，已存在的系统环境变量优先。修改 `.env` 后需重启进程。

设置以下三项可关闭自动采集（不禁止手动管理接口）：

```dotenv
AUTO_SYNC_ON_STARTUP=0
BOOTSTRAP_RECENT_NEWS_ON_STARTUP=0
SCHEDULER_ENABLED=0
```

`SCHEDULED_SYNC_INTERVAL_HOURS` 是从调度器启动后计算的实际小时间隔，不保证整点执行。测试会在导入应用前使用临时数据库，并禁止外部网络及真实采集线程，不依赖工作目录里的新闻库：

```bash
python -m pytest
python -m mypy app/ --ignore-missing-imports
python -m flake8 app/ --count --select=E9,F63,F7,F82 --show-source --statistics
```

非 UI 实施记录及剩余任务见 [功能待办规划](docs/NON_UI_ROADMAP.md)。


## 公众号研读（首版）

`/learning` 提供公众号考点摘录与折叠问答，`/api/learning` 和 `/api/learning/{id}` 提供结构化结果。每条内容保留原文段落编号、账号及链接；规则摘录不等于 AI 总结，不宣称已核对教材或完整覆盖音视频和图片。

本地 WeRSS 目前订阅肖秀荣教授和考研政治徐涛。配置 `WERSS_DATABASE_PATH` 指向其 SQLite 数据库后，主项目只读导入白名单账号的文字正文，保存至独立 `learning_materials` 表。启动通过 `init_db()` 执行版本化 SQLite 迁移；旧库升级前应备份。该桥接仅适用于两个服务能访问同一磁盘文件的部署，尚非通用远程 RSS 接口。

本机启动：

```powershell
.\scripts\run_learning_local.ps1
```

入口为 `http://127.0.0.1:8004/learning`。脚本先导入一次，然后随主服务每 15 分钟导入已采集内容；WeRSS 自身每两小时获取文章。关闭主项目调度器后不会自动导入。新增内容按来源 ID 去重，正文或标题变化时重新整理，资料修订以递增版本保存，历史正文、标题和依据可回看。

手动导入接口为 `POST /api/learning/sync`，必须配置 `SYNC_ADMIN_TOKEN` 并通过 `X-Sync-Token` 请求头提交令牌；未配置令牌时禁止该接口写入。也可在本地执行 `from app.materials import sync_materials; sync_materials()`。

限制：目前按已知模板识别考点和编号自测，不支持的文章保留文字并提示待整理；作者标星与系统判断分开。两个账号主题不同时分别呈现，不强行合并成一个结论。来源可能漏采多篇更新，发布时间未验证；尚未接入模型摘要、音频转写、跨文章语义合并和审核操作。


公众号运行诊断见 `/status` 和 `/api/learning/status`：上游库可读不代表授权正常，导入无新增不代表公众号无更新。主项目导入状态持久化；失败保留最后成功时间，重启识别未完成导入。文章来源时间未确认时保持空值，导入时间单独记录。

## 数据库升级与学习资料版本

当前数据库版本为 3。启动时按 `schema_migrations` 顺序升级；新库和原有无版本号数据库均适用。升级不改变新闻与学习资料 ID，较新且不受当前程序支持的数据库版本会拒绝启动。现阶段仅支持 SQLite。

旧学习资料升级时保存为版本 1，标记 `legacy_snapshot`：可保留升级前已有的标题、结构化正文和依据，但无法恢复此前没有保存的原始 HTML。后续更正与正文快照在同一事务提交，导入失败不会留下半条修订；重复导入不增加版本。历史版本为只读。

版本接口：`GET /api/learning/{id}/revisions`、`GET /api/learning/{id}/revisions/{revision}`。固定引用可使用 `/learning/{id}?revision=1#e-L1`，普通 `/learning/{id}` 和已有收藏仍打开最新内容。

升级前执行（目标文件必须尚不存在）：

```powershell
python scripts/database_backup.py test.db backup-before-upgrade.db
```

恢复时先停止应用及后台写入，再将备份复制到一个新文件并把 `DATABASE_URL` 指向它。脚本使用 SQLite backup API 并检查完整性，禁止覆盖已有目标；不会自动执行破坏性的降级迁移。若需要回到升级前版本，应同时恢复对应应用版本与升级前备份。

## 考点关联（候选关系）

从 `/learning` 的“按考点研读”进入 `/knowledge`，或从资料详情进入对应考点。当前目录覆盖 12 种明确的题目或表述模板，考点使用稳定编号；只关联已抽取、具有有效原文段落依据的条目，不以关键词相同直接合并。新资料和更正导入时自动关联，启动时补齐已有版本的关系，重复运行不重复添加。

`GET /api/knowledge` 返回索引；`GET /api/knowledge/{point_id}` 返回各来源的问答、作者标记、待核对提示与固定版本依据。默认只展示每篇资料最新版本的关联，`?history=true` 可查看历史关联；不同老师的答案分别呈现。教材版本尚未指定，不代表已对照某年考试大纲。

关系初始为 `candidate`。管理员可调用 `PUT /api/knowledge-links/{link_id}/review`，通过 `X-Sync-Token` 请求头提交已配置的 `SYNC_ADMIN_TOKEN`，JSON 请求体为 `{"status":"confirmed"}`、`{"status":"rejected"}` 或 `{"status":"candidate"}`。拒绝的关联不再展示，重建保留审核决定；确认只针对当前固定版本，后续更正的关系仍需重新确认。当前没有网页审核界面。

这是基于明确模板的候选组织能力，未接入模型或向量检索，不自动生成跨来源统一答案，也尚未把新闻、图像或音频内容关联到考点。现有两篇真实资料分别命中不同考点，多来源同考点展示通过合成用例验证，不能据此宣称真实资料已形成交叉印证。
