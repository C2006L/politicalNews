# 可选完整后端的 HTTPS 配置

当前静态阅读站使用 `http://43.153.144.83:3011/`，没有配置域名或证书。静态发布步骤见 [静态阅读版说明](../docs/static-reading.md)，不要把本文作为现有网站更新命令。

仓库 `nginx.conf` 保留了可选完整后端的 HTTPS 模板，`study.example.com` 是占位域名；只有确定自有域名、DNS、证书和实际部署方式之后才可使用。已有服务占用 80/443 时，应先规划共存方式。

如使用该模板，需要提供 `fullchain.pem` 和 `privkey.pem`，并核对容器挂载位置与 Nginx 配置。证书和私钥留在部署环境，禁止提交到 GitHub。

旧服务器的 IP、证书示例和访问地址已移除；本文不承诺 IP 证书申请或自动续签已经实现。
